# java-lotto-precourse

## 기능 요구사항

### 1. 입력

- 사용자로부터 **로또 구입 금액**을 입력 받는다.
    - 구입 금액은 1,000원 단위로 입력 받는다.
- 사용자로부터 **당첨 번호**를 입력 받는다.
    - 쉼표(,)를 기준으로 번호를 구분한다.
- 사용자로부터 **보너스 번호** 1개를 입력 받는다.

### 2. 로또 발행 및 관리

- 로또 1장의 가격은 1,000원이다.
- 사용자가 입력한 구입 금액을 기준으로 구매 가능한 로또 수를 계산한다.
- 계산된 수만큼 로또를 발행한다.
- 각 로또는 1~45 사이의 **중복되지 않는 6개의 번호**로 구성된다.

### 3. 당첨 로또 추첨

- 당첨 번호는 1~45 사이의 **중복되지 않는 6개의 번호**를 `Randoms.pickUniqueNumbersInRange()`을 통해**무작위로 추첨**한다.
- **보너스 번호**는 1~45 범위에서 **당첨 번호와 중복되지 않도록** 별도로 `Randoms.pickUniqueNumbersInRange()`을 통해 **무작위 추첨**한다.

### 4. 당첨 기준 및 상금

| 순위 | 당첨 기준             | 상금             |
|----|-------------------|----------------|
| 1등 | 6개 번호 일치          | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원    |
| 3등 | 5개 번호 일치          | 1,500,000원     |
| 4등 | 4개 번호 일치          | 50,000원        |
| 5등 | 3개 번호 일치          | 5,000원         |

### 5. 당첨 결과 계산 및 출력

- 사용자가 구매한 로또와 **당첨 로또**를 비교한다.
- 각 로또의 **일치 개수**와 **보너스 번호 일치 여부**를 확인한다.
- 당첨 기준에 따라 순위를 결정하고, 등수별 **당첨 내역 및 총 수익률**을 계산한다.

### 6. 출력

- 발행한 로또 수량 및 번호를 출력한다.
    - 로또 번호는 **오름차순**으로 정렬하여 출력한다.
    ```bash
    8개를 구매했습니다.
    [8, 21, 23, 41, 42, 43]
    [3, 5, 11, 16, 32, 38]
    [7, 11, 16, 35, 36, 44]
    [1, 8, 11, 31, 41, 42]
    [13, 14, 16, 38, 42, 45]
    [7, 11, 30, 40, 42, 43]
    [2, 13, 22, 32, 38, 45]
    [1, 3, 5, 14, 22, 45]
- 당첨 내역을 출력한다.
    ```bash
    3개 일치 (5,000원) - 1개
    4개 일치 (50,000원) - 0개
    5개 일치 (1,500,000원) - 0개
    5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
    6개 일치 (2,000,000,000원) - 0개
- 수익률을 출력한다.
    - 수익률은 소수점 둘째 자리에서 반올림하여 출력한다.
    ```bash
    총 수익률은 62.5%입니다.

### 7. 예외 처리

- 모든 예외 상황에서 `IllegalArgumentException`을 발생시키며, `[ERROR]`로 시작하는 에러 메세지를 출력한다.
- 입력값이 잘못된 경우 오류 메세지를 출력한 뒤 **해당 입력부터 다시 입력을 받는다.**

- 입력 관련 예외
    1. 구입 금액
        - 1,000원 단위가 아닐 경우 예외 발생
        - 음수 또는 0원 입력 시 예외 발생
        - 숫자가 아닌 값 입력 시 예외 발생
    2. 당첨 번호
        - **1~45 사이 번호**가 아닐 경우 예외 발생
        - **6개 초과** 입력 시 예외 발생
        - **6개 미만** 입력 시 예외 발생
        - 중복된 번호 입력 시 예외 발생
        - 숫자가 아닌 값 입력 시 예외 발생
    3. 보너스 번호
        - **1~45 사이 번호**가 아닐 경우 예외 발생
        - 1개 초과 입력 시 예외 발생
        - 당첨 번호와 중복될 경우 예외 발생
        - 숫자가 아닌 값 입력 시 예외 발생

## 테스트

### 1. 정상 동작 테스트

| 테스트 항목   | 검증 내용                                                                                   |
|----------|-----------------------------------------------------------------------------------------|
| 구입 금액 입력 | 입력 받은 금액을 1,000으로 나눈 값만큼 로또가 발행되는지 검증                                                   |
| 당첨 번호 입력 | 쉼표(,) 기준으로 정확히 6개의 숫자를 파싱하고, 중복 및 범위 검증이 올바르게 수행되는지 확인                                  |
| 보너스 번호 입력 | 당첨 번호와 중복되지 않으며, 1~45 범위의 숫자로 처리되는지 검증                                                  |
| 로또 발행    | 구입 금액 만큼 로또가 생성되며, 각 로또는 1~45 범위의 중복 없는 6개 숫자로 구성되는지 확인                                 |
| 로또 번호 정렬 | 각 로또 번호가 오름차순으로 정렬되어 출력되는지 검증                                                           |
| 당첨 결과 비교 | 각 로또의 일치 개수와 보너스 번호 일치 여부가 정확히 계산되는지 확인                                                 |
| 당첨 등수 판별 | 일치 개수에 따라 올바른 순위(1~5등)가 판별되는지 검증                                                        |
| 수익률 계산   | 당첨 결과를 바탕으로 전체 수익률이 소수점 둘째 자리에서 반올림되어 계산되는지 확인                                          |
| 로또 번호 생성 | Randoms.pickUniqueNumbersInRange()를 통해 1~45 범위의 중복 없는 6개 번호가 생성되는지 검증 |
